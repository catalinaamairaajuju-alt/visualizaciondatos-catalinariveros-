
## Definición
La recolección de datos es el proceso mediante el cual se obtienen los datos necesarios para responder una pregunta, realizar un análisis o cumplir un determinado objetivo.

## Explicación
Los datos pueden obtenerse desde diferentes fuentes y mediante distintas estrategias. La forma en que son recolectados puede afectar posteriormente su calidad y utilidad.

## Resumen personal
Entiendo la recolección de datos como la etapa en la que obtenemos la materia prima que posteriormente será procesada, analizada y visualizada.

## Importancia
Una recolección adecuada permite disponer de datos pertinentes para el análisis y disminuye problemas en las etapas posteriores.
