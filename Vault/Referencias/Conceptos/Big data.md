
## Definición
Big Data se relaciona con conjuntos de datos cuyo volumen, variedad o características generan desafíos para su almacenamiento, procesamiento y análisis.

## Explicación
El crecimiento de los datos hace necesario utilizar tecnologías y procedimientos capaces de trabajar con grandes cantidades y diferentes tipos de información.

La visualización cumple un papel importante al permitir explorar y comunicar resultados obtenidos a partir de estos conjuntos de datos.

## Resumen personal
Entiendo Big Data como el trabajo con grandes y complejos conjuntos de datos que requieren herramientas y métodos adecuados para poder analizarlos.

## Importancia
Permite abordar escenarios donde existe una gran cantidad y diversidad de datos y donde los métodos tradicionales pueden resultar insuficientes.
