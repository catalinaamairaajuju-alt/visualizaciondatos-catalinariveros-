
## Definición
Las fuentes de datos corresponden a los diferentes lugares, sistemas o medios desde los cuales pueden obtenerse datos para realizar un análisis.

## Explicación
La selección de las fuentes depende del objetivo del análisis. Es necesario evaluar su procedencia, confiabilidad y calidad antes de utilizar los datos obtenidos.

## Resumen personal
Entiendo las fuentes de datos como el origen desde donde obtenemos los datos que necesitamos para realizar un análisis.

## Importancia
Conocer la fuente permite comprender el origen de los datos y evaluar si son apropiados para el objetivo planteado.
